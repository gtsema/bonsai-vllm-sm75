# SM75 / RTX 2080 Ti port

This fork adds an experimental CUDA fallback for NVIDIA Turing (compute capability 7.5), including RTX 2080 / 2080 Ti.

The upstream plugin requires SM80 because its GEMV kernel uses the Ampere+ BF16 Tensor Core instruction:

```text
mma.sync.aligned.m16n8k16.row.col.f32.bf16.bf16.f32
```

Turing has FP16 Tensor Cores but no BF16 Tensor Cores. On `__CUDA_ARCH__ < 800`, the modified kernel therefore:

1. keeps the vLLM-visible activation tensor in BF16;
2. converts the BF16 activation fragments to FP16 in registers;
3. converts the ternary LUT values to FP16;
4. uses `mma.sync.aligned.m16n8k16.row.col.f32.f16.f16.f32`;
5. keeps FP32 accumulation and converts the result back to BF16.

The SM80+ path remains the original BF16 Tensor Core implementation.

## Important

This is an experimental port. It has not been compiled or benchmarked on a physical SM75 GPU in this source distribution. The first test should be a small model/load or a standalone kernel test, followed by a numerical comparison against the dequantize+matmul path.

The Dockerfile now includes `7.5` in `TORCH_CUDA_ARCH_LIST`.
